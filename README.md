# StructureSpawner

Plugin Spigot/Paper pour Minecraft 26.3 (Java 25).

- `/structure` : ouvre le menu (vise un bloc avant de taper la commande, la structure apparaît dessus)
- `/structure spawn <id>` : ouvre directement la confirmation pour une structure
- `/structure list` : liste les structures
- `/structure undo` : annule ta dernière construction

Permission : `structurespawner.use` (op par défaut).

## Obtenir le .jar
1. Pousse ce dossier sur un dépôt GitHub.
2. Onglet Actions > Build > télécharge l'artefact `StructureSpawner`.
3. Dépose `StructureSpawner.jar` dans `plugins/` du serveur et redémarre.

Si ta version de Minecraft est différente, change `spigot.version` dans `pom.xml`.
